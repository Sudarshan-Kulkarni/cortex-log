Cortex Log — Technical Reading Tracker & Anki Companion

Snapshot generated from finished proof-of-concept source code (post-Final Review commit 2aca23e). Note: this file is a static snapshot of the repository structure and can drift as the codebase evolves.

What it does: Cortex Log lets you log technical engineering blogs on a monthly reading calendar (turning today's yellow indicator dot green), dispatches logged articles over a message queue (GCP Pub/Sub) to scrape and chunk the text into detail-focused multiple-choice flashcards with Gemini (gemini-2.5-flash), supports per-user card editing and curation in Neon PostgreSQL, and syncs approved cards into Anki Desktop through a lightweight outbound Anki 2.1+ add-on.

1. Main Pieces at a Glance

Frontend (frontend/)

Next.js 15 App Router + Tailwind CSS in the Techy Manila Blueprint theme (#F3E9D2).

  • src/app/page.tsx — Top blueprint header & two-tab switcher (Calendar / Flashcards).
  • src/components/CalendarTab.tsx — Monthly 7-column grid, green/yellow status dots, future-day lock, and blog logging drawer.
  • src/components/FlashcardsTab.tsx — Expandable blog accordions, raw-text fallback form, 2-column flashcard grid, inline editor, custom card creator, and Anki approval controls.

Backend & Worker (backend/)

FastAPI + SQLAlchemy 2.0 + GCP Pub/Sub + Google GenAI SDK.

  • app/routers/calendar.py — GET /api/calendar and deduplicated POST /api/blogs/log.
  • app/services/pubsub.py & app/worker.py — Pub/Sub publisher/subscriber for blog-ingestion and anki-delivery.
  • app/services/scraper.py & app/services/llm.py — Article extraction (trafilatura) and ~900-word chunked Gemini flashcard generation.
  • app/routers/flashcards.py & app/routers/anki.py — Per-user card overrides and Anki pull/ack queue endpoints.

Anki Desktop Add-on (anki_addon/)

Outbound pull-and-ack plugin inside Anki 2.1+ (addons21/cortex_log_sync).

  • cortex_log_sync/__init__.py — Hooks aqt.gui_hooks.profile_did_open and Tools -> Sync Cortex Log Cards.
  • cortex_log_sync/config.json — Points backend_url to local or Cloud Run backend.

Cloud IaC (terraform/)

End-to-end multi-provider Terraform (hashicorp/google + kislerdm/neon).

  • main.tf — Provisions Neon Serverless Postgres, GCP Pub/Sub topics/subscriptions, Artifact Registry, Cloud Build image push, and Cloud Run v2 services.

3. Code Route (Reference Route: 3 Stops)

Follow a single action—approving a flashcard and syncing it into Anki Desktop—across 3 files in your editor:

STOP 1 Browser Trigger & Optimistic Badge Update — frontend/src/components/FlashcardsTab.tsx (anchor: handleApproveCard)

When you click ✓ Approve on a card, handleApproveCard calls approveFlashcard(card.card_id) in frontend/src/lib/api.ts, updates that card's badge in React state to QUEUED FOR ANKI, and refreshes the top-bar queue counter.

STOP 2 Pub/Sub Publish, Pull & Acknowledge Endpoints — backend/app/routers/anki.py (anchors: approve_flashcard_for_anki, pull_queued_anki_cards, acknowledge_anki_cards)

approve_flashcard_for_anki resolves your per-user row in user_flashcards, builds the HTML front/back with _build_anki_card_html, and publishes the payload to the GCP Pub/Sub anki-delivery topic via publish_anki_delivery in backend/app/services/pubsub.py. When Anki Desktop calls POST /api/anki/pull and POST /api/anki/ack, the backend pulls waiting Pub/Sub ack_ids, acknowledges them, and marks the rows synced_to_anki.

STOP 3 Anki Desktop Startup Hook & Note Insertion — anki_addon/cortex_log_sync/__init__.py (anchors: _register_anki_hooks, sync_cortex_log_cards)

Inside Anki Desktop, _register_anki_hooks attaches sync_cortex_log_cards to gui_hooks.profile_did_open (and adds Tools -> Sync Cortex Log Cards). It makes an outbound HTTP request to your Cloud Run backend, creates/opens the "Cortex Log" deck with mw.col.decks.id(deck_name), inserts each note via mw.col.add_note(note, deck_id), and ACKs the synced IDs.

4. "To Change This, Start Here" Pointers

Change how Gemini chunks articles or writes multiple-choice distractors

Open backend/app/services/llm.py and look at chunk_text_by_words (currently target_words = 900, overlap_words = 100) and SYSTEM_PROMPT inside generate_summary_and_flashcards.

Adjust calendar future-day rules or Flashcards page sort order (Final Review edits)

Future calendar cells are disabled via const isFuture = dateStr > todayIso in frontend/src/components/CalendarTab.tsx. The Flashcards page sort order is controlled in backend/app/routers/flashcards.py inside get_logged_blogs_with_flashcards (.order_by(UserBlog.created_at.desc(), UserBlog.id.desc())).

Customize the HTML styling of cards inside Anki Desktop

Open backend/app/routers/anki.py and edit _build_anki_card_html, which formats the [CORTEX LOG // Title] header, multiple-choice <ul> list, and source URL link on the card back.

Switch the Anki add-on between Cloud Run and local development

Edit "backend_url" in anki_addon/cortex_log_sync/config.json and re-run ./anki_addon/cortex_log_sync/install_addon.sh.

5. A Practice to Reuse

Separating build-time vs. runtime configuration in containerized web apps: During our Cloud Run deployment (Slice 5), the frontend initially threw Failed to fetch even though NEXT_PUBLIC_API_URL was set on the Cloud Run service. Inspecting the rendered HTML revealed that Next.js's compiler inlines process.env.NEXT_PUBLIC_* string literals at docker build time, baking in the Dockerfile default (http://localhost:8010).

The reusable pattern: In frontend/src/app/layout.tsx (marked export const dynamic = "force-dynamic"), we read a non-prefixed server environment variable at request time (envMap["BACKEND_API_URL"]) and inject it into window.__CORTEX_API_URL__, which frontend/src/lib/api.ts reads first via getApiBase(). On any future Next.js + Docker/Cloud Run/Kubernetes project, this lets you build the frontend image once in CI/Cloud Build and inject environment-specific backend URLs at container startup without rebuilding the image.

6. How to Run, Deploy, or Tear Down

Local Development

# Terminal 1 — FastAPI Backend & Worker (port 8010)
cd backend && ./.venv/bin/uvicorn app.main:app --reload --port 8010

# Terminal 2 — Next.js Frontend (port 3010)
cd frontend && npm run dev

# Install/Update Anki Desktop Add-on
./anki_addon/cortex_log_sync/install_addon.sh

Cloud Run + Neon + Pub/Sub via Terraform

# Provision or update the full cloud stack
cd terraform
terraform init
terraform apply

# Tear down all cloud resources cleanly when finished
terraform destroy
